> 参赛：广东亚视演艺职业学院「数创铸魂·码承文脉」小程序大赛（智慧校园方向）

> 视觉：仿 `www.cxl--package.top`（CXL 避难所 / Firefly 清爽二次元卡片风）

## 一、总体架构

```
┌──────────────┐         ┌────────────────────────────┐         ┌──────────────┐
│  学生端小程序 │         │      微信云开发 CloudBase     │         │  教师端小程序 │
│ (AppID-A)    │         │  ├─ 云数据库（文档库）        │         │ (AppID-B)    │
│              │  callFunction  ├─ 云函数（auth/导入/请假/公告/AI）│  callFunction  │
│ 登录/改密/公告│ ───────▶ │  └─ 云存储（头像/请假证明）   │ ◀─────── │ 班级/审批/公告 │
│ /请假/AI     │         │                            │         │              │
└──────────────┘         └────────────────────────────┘         └──────────────┘
```

- 两个小程序**各自一个 AppID**，但都填**同一个云开发环境 ID**，所以共享同一套数据库与云函数。
- 所有业务逻辑（注册、登录、鉴权、导入、请假、公告、AI）都放在**云函数**里，密钥/密码不落前端。
- 前端只负责展示和调云函数，符合你"没服务器、拿云开发顶"的诉求。

## 三、角色与核心流程

### 3.1 教师端 onboarding（解决"首批数据从哪来"）

1. **初始化/种子（一次性）**：由超管（你们/学校）先把 **届 → 学院 → 专业 → 班级** 组织树和**教师账号**录进云数据库（教师带默认密码、`mustChangePwd=true`）。
2. 教师打开教师端 → 输入**工号 + 密码**登录。
3. 若 `mustChangePwd=true` → 强制改密（弹窗不可关）。
4. 改密后 → 系统按 `classIds` 显示「我的班级」→ 选择并提交 → 进入后台。
5. 后台：建/维护班级、导入学生、请假管理、公告发布。

> 兜底：若某教师没被预录，提供"申请建班"入口，教师自建班级并导入学生后也能用（演示不怕卡）。

### 3.2 学生端 onboarding（你描述的流程）

1. 学校把**姓名 + 学号**发给教师 → 教师在教师端**导入表格** → 云函数批量注册学生账号（**账号=学号，密码默认 123456**，全部 `mustChangePwd=true`）。
2. 学生打开学生端 → 用**学号 + 123456** 登录。
3. 首次登录强制改密（弹窗不可关，且**后端也拦截**其它请求）。
4. 改密后进入首页：看公告、请请假、查状态、AI 答疑、个人中心。

| name      | string | 展示名，如 `"26届"`    |
| createdAt | date   | 创建时间             |

### colleges（学院）

| 字段      | 类型     | 说明               |
| ------- | ------ | ---------------- |
| gradeId | string | 所属届 `_id`        |
| name    | string | 学院名，如 `"信息工程学院"` |

### majors（专业）

| 字段        | 类型     | 说明              |
| --------- | ------ | --------------- |
| collegeId | string | 所属学院 `_id`      |
| name      | string | 专业名，如 `"计算机应用"` |

### classes（班级）

| 字段                            | 类型     | 说明          |
| ----------------------------- | ------ | ----------- |
| gradeId / collegeId / majorId | string | 层级归属        |
| name                          | string | 如 `"3班"`    |
| headTeacherId                 | string | 班主任教师 `_id` |
| studentCount                  | number | 冗余计数（可选）    |

### teachers（教师）

| 字段                  | 类型     | 说明                                   |
| ------------------- | ------ | ------------------------------------ |
| teacherNo           | string | 工号（登录账号）                             |

| collegeId           | string | 所属学院                                 |
| classIds            | array  | 管理的班级 `_id` 列表                       |

| passwordHash / salt | string | **密码哈希 + 盐**，绝不明文                    |
| mustChangePwd       | bool   | 是否强制改密（默认 true）                      |

### students（学生）

| 字段                            | 类型     | 说明              |
| ----------------------------- | ------ | --------------- |
| studentNo                     | string | 学号（登录账号，唯一索引）   |
| name                          | string | 姓名              |
| classId / gradeId / collegeId | string | 归属              |
| passwordHash / salt           | string | 哈希 + 盐          |
| mustChangePwd                 | bool   | 默认 true（首次登录改密） |
| status                        | string | `"active"` 等    |
| createdAt                     | date   |                 |

### leaves（请假）

| 字段                                     | 类型     | 说明                                  |
| -------------------------------------- | ------ | ----------------------------------- |
| studentId / studentNo / name / classId | string | 申请人信息                               |
| type                                   | string | 病假/事假/其它                            |
| reason                                 | string | 原因                                  |
| start / end                            | date   | 起止                                  |
| status                                 | string | `pending` / `approved` / `rejected` |
| approveBy / approveAt / comment        | —      | 审批人、时间、意见                           |
| attachments                            | array  | 证明图片 fileID（云存储）                    |
| createdAt                              | date   |                                     |

### announcements（公告）

| 字段              | 类型     | 说明                 |           |                            |
| --------------- | ------ | ------------------ | --------- | -------------------------- |
| title / content | string | 标题/正文              |           |                            |
| publisherId     | string | 发布教师 `_id`         |           |                            |
| scope           | object | \`{type:'class'    | 'college' | 'school', classId?}\` 定向范围 |
| readBy          | array  | 已读学生 `_id` 列表（统计用） |           |                            |
| createdAt       | date   |                    |           |                            |

### sessions（登录态，自定义账号登录用）

| 字段            | 类型     | 说明              |
| ------------- | ------ | --------------- |
| token         | string | 登录令牌（随机长串，唯一索引） |
| userId / role | string | 对应用户 `_id` 与角色  |
| expireAt      | date   | 过期时间（如 7 天）     |

## 五、云函数 / 接口设计

| 云函数                           | 输入                                  | 作用                                                   |
| ----------------------------- | ----------------------------------- | ---------------------------------------------------- |
| `login`                       | `{account, password, role}`         | 校验账号密码 → 查 `mustChangePwd` → 写 `sessions` 返回 token   |
| `changePassword`              | `{token, oldPwd, newPwd}`           | 改密（**不受 mustChangePwd 拦截**，其它接口都受）                   |
| `auth` 公共校验                   | token                               | 每个受保护函数先调：解析 token → 取用户 → 若 `mustChangePwd` 且非改密则拒绝 |
| `importStudents`              | `{rows:[{studentNo,name,classId}]}` | 校验/去重 → 批量 upsert 学生（默认密码哈希）                         |
| `createClass` / `seedOrg`     | 组织树数据                               | 初始化届/学院/专业/班级/教师（admin 用）                            |
| `submitLeave`                 | 请假表单                                | 学生提交请假（校验归属班级）                                       |
| `listLeaves` / `approveLeave` | 筛选/审批                               | 教师按班级看、审批                                            |
| `publishAnnouncement`         | 公告内容+scope                          | 教师发布，按 scope 定向                                      |
| `listAnnouncements`           | classId                             | 学生拉取自己班级/学院/全校公告                                     |
| `aiChat`                      | 问答                                  | 复用之前核心：校园制度 RAG 答疑（保 AI 20% 分）                       |

## 六、权限与越权防护（比赛看安全合规）

- 每个受保护云函数入口先 `auth(token)`：解析用户 → 取 `role`、`classIds`。
- **学生**：只能读自己班级的公告、提交/查自己的请假；**不能**调教师接口（发布/审批）。
- **教师**：只能操作 `classIds` 内的学生与请假；A 教师的班级 B 教师读不到。
- 所有 DB 查询带 `classId` 过滤，不在前端传"看全部"。
- 越权访问统一返回 `403`。

## 七、安全设计（你描述的漏洞，这里堵上）

1. **强制改密服务端校验**：`mustChangePwd=true` 时，除 `changePassword` 外所有接口返回 `FORCE_PWD_CHANGE`，前端弹不可关窗口——**即使换客户端也绕不过**。
2. **密码哈希**：用 Node 内置 `crypto.scrypt`（无需装原生依赖）做 盐+哈希，导入时的 `123456` 也哈希存储，**绝不明文**。
3. **学号/工号可枚举**：首次登录强制改密（123456 仅临时可用）+ 登录失败**限流**（同一账号 5 次/10 分钟锁定）+ 改密后立即失效旧 token。
4. **表格导入健壮**：字段校验（学号格式、姓名非空）、重复学号跳过/更新、文件大小与行数上限、导入前可预览、失败回滚、防 CSV 注入。
5. **传输**：演示用开发者工具"不校验合法域名"即可；正式需 HTTPS（云开发自带）。

## 八、隐私合规（章程硬指标，漏了会扣分甚至取消）

- 单列**隐私政策**页面（学生端/教师端都要入口）：说明收集字段（学号、姓名、班级）、用途、最小必要原则、不对外共享。
- 只收**必要字段**，不额外采集手机号/人脸等。
- 数据仅用于校园服务，符合《个人信息保护法》《网络安全法》。
