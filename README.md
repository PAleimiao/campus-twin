# 广演校园 · campus-twin

智慧校园小程序。**同一个仓库里包含教师端和学生端两套小程序**，它们共用一套后端接口。

```
campus-twin/
├── local-server/    本地后端（Node，零依赖）——★ 现在默认跑这个，双击 bat 就能用
├── student-end/     学生端小程序
├── teacher-end/     教师端小程序
├── cloud/           云开发版后端（备选方案，需开通云环境）
├── design/          设计方案与数据模型
└── tools/           生成演示图片的脚本
```

---

> **第一次接触这个项目？直接看 [`操作手册.md`](操作手册.md)**，里面有一步一步截图级的启动说明、演示流程和故障对照表。下面只是精简版。

## 快速开始（推荐：本地模式）

**1. 装 Node.js**（已装可跳过）
去 https://nodejs.org/ 下载 18+ 版本，一路下一步装完。

**2. 启动后端**
双击 `local-server/启动本地服务.bat`。
第一次会自动写入演示账号；看到「本地后端已启动」就是好了。**这个黑窗口要一直开着**，关掉就停服。

**3. 用微信开发者工具打开小程序**
`导入项目` → 目录选 `student-end`（学生端）或 `teacher-end`（教师端）。
然后 **详情 → 本地设置 → 勾选「不校验合法域名」**（两端的配置里已经是 `urlCheck: false`，通常默认就开着）。

> 后端不用管，它是两端共享的：教师在教师端发的资讯，学生端首页立刻能看到。

首次登录会**强制改密**；想把数据恢复成初始样子：`cd local-server && node seed.js --reset`。

已实现的完整链路：**登录 → 强制改密 → 重新登录 → 教师端发内容 → 学生端看到**。

**已实现的功能模块**（学生端 / 教师端）：

| 模块 | 学生端 | 教师端 |

## 两种后端模式

| | 本地模式（默认） | 云开发模式 |
| --- | --- | --- |
| 跑在哪 | 你自己的电脑上 | 微信云开发 CloudBase |
| 要不要开通云环境 | 不用 | 要 |
| 数据存哪 | `local-server/data/db.json` | 云数据库集合 |
| 图片存哪 | `local-server/public/uploads/` | 云存储 fileID（`cloud://`） |
| 适合干嘛 | 日常开发、演示、答辩 | 正式部署上线 |

切换只改两端 `config.js` 里的**一个值**：

```js
backend: 'local',                        // 'local' = 本地后端；'cloud' = 微信云开发
apiBase: 'http://localhost:3000/api',    // 'local' 模式用（真机换成电脑局域网 IP）
cloudEnv: 'your-env-id',                 // 'cloud' 模式用，两端必须填同一个环境 ID
```

改成 `'cloud'` 后照 [`cloud/README.md`](cloud/README.md) 部署 6 个云函数。**业务代码一行都不用改**——
两套后端的接口完全同名同参（`login / changePassword / getNews / manageNews / importStudents / seedOrg`）。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 提示「连不上本地服务」 | 后端没开。去 `local-server` 双击 `启动本地服务.bat` |
| bat 说找不到 Node | 没装 Node 或装完没重开终端。去 nodejs.org 装 18+ |
| 启动报「端口已被占用」 | 3000 被别的程序占了。`PORT=3001 node server.js`，同时把 `config.js` 的 `apiBase` 端口改成 3001 |
| 真机预览连不上 | `apiBase` 里不能用 `localhost`，要换成**电脑的局域网 IP**（服务启动时会打印）。手机和电脑同一个 Wi-Fi |
| 图片不显示 | 图片地址必须是 `http://` 开头的绝对地址；真机同样要用局域网 IP，不能写 `localhost` |
| 登录后一直让改密码 | 这是设计如此：初始密码必须改一次，改完重新登录就正常了 |
| 想看/改数据 | 直接用记事本打开 `local-server/data/db.json` |
| 两端 appid 不一样 | `student-end` 是 `wx2c7fed86f9f91414`，`teacher-end` 是 `touristappid`（游客模式，无需 appid 也能预览）。要上架就把两边都换成自己的小程序 appid |
